### Problem Statement
Tickets are sold for a concert at $20 each. If 10 tickets are bought then the discount is 10%, if 20 tickets are bought the discount is 20%. No more than 25 tickets can be bought in a single transaction.

### What to do?
- [x] Design a program that takes number of tickets as input & outputs total cost of tickets.
- [x] Do a dry run using sample data & trace table to check for any mistakes in design
- [ ] Code the designed program in python
- [ ] Implement a `presence check` to ensure program handles error when there is no user input.
- [ ] Implement a `type check` to ensure program handles non-integer input error.
- [ ] Implement a `range check` to ensure program handles negative integer input error.
