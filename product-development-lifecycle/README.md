# What is product development lifecycle
A systematic way of building & maintaining software.

# Stages of product development lifecycle
1. Analyse
2. Design
3. Coding
4. Testing
5. Maintenance

# Scenario
A sports club is offering memberships in four different sports - football, basketball, cricket & archery. They have slots for only 10 members per sport. Develop a program that helps this sports club decide whether they can add new members or not.

## Analyse
1. Define the requirements for the program
2. Break down the problem if it is too big to handle

## Design
Create a detailed design of program's working & architecture. This will act as our blueprint when we move to coding stage.
It can documented using structure chart, flowchart or pseudocode. We will use flowchart as it is most appropriate for this scenario. Structure charts are useful when you have several different systems interacting with one another.
